# Computer Vision Study

「33개 프로젝트로 완성하는 컴퓨터비전 딥러닝 심화 과정」을 수강하며  
컴퓨터 비전과 딥러닝의 주요 모델을 학습하고 실습한 내용을 기록하는 저장소입니다.

각 모델의 이론과 구조를 공부한 뒤, 강의를 따라 PyTorch 및 TensorFlow 기반 실습을 진행하고 있습니다.

현재 강의를 수강 중이며, 학습 진행에 따라 실습 코드를 지속적으로 추가하고 있습니다.
